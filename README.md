# Realm 中文转发管理工具

在 Linux VPS 上用**中文菜单**管理 **TCP + UDP 端口转发**。用法与 [xray-deploy](https://github.com/fengqi0216/xray-deploy) 类似：**一条命令安装，以后输入 `rnode` 打开菜单。**

```text
你的客户端 → 入口服务器（安装本工具）→ 原节点 / 目标服务
```

请先准备一个已经能正常使用的节点或服务，以及它的地址和端口。

## 安装

推荐使用 **Debian 12 / 13、Ubuntu 22.04 / 24.04**。登录**入口服务器**，复制整行执行：

```bash
sh -c "$(curl -fsSL https://raw.githubusercontent.com/FQForge/realm-deploy/main/install-realm.sh)"
```

安装完成会自动打开中文菜单。以后输入：

```bash
rnode
```

普通用户使用 `sudo rnode`。首次创建转发时，会自动下载 Realm 官方内核、启动服务并开启开机自启。

如果提示 `curl: command not found`，先安装 curl；Debian / Ubuntu 的 root 用户可执行 `apt-get update && apt-get install -y curl`，然后重试。没有 root / sudo 权限时，请先用 `su -` 切换 root。

## 第一次创建转发

1. 主菜单选择 **1 · 快速创建转发**。
2. 按下面的例子填写 **4 项**：

   | 提示 | 示例怎么填 | 去哪里找 |
   | --- | --- | --- |
   | 目标服务器 IP / 域名 | `198.51.100.20` | 原节点的服务器地址，不带 `https://` 和端口 |
   | 目标服务端口 | `443` | 原节点原本的端口 |
   | 入口服务器本机监听端口 | `20000`，也可直接回车自动选 | 给客户端连接的新端口 |
   | 入口公网 IP / 域名 | 自动识别，直接回车；也可手动填 `203.0.113.10` | 通常就是 SSH 登录这台入口 VPS 的地址 |

3. 检查显示的转发路径，输入 **y** 保存。名称自动生成，TCP + UDP 同时开启。

上面的 IP 仅作示例，使用时换成自己的真实地址。**任一步输入 `q` 都能取消，确认前不会创建规则。** 入口公网地址暂时不知道可留空，之后通过主菜单 **4 → 修改** 补填。

**本机监听 IP 也会自动选择：** 普通 VPS 优先使用本机网卡上的公网 IPv4；如果公网 IP 由 NAT 映射，监听使用 `0.0.0.0`，客户端仍填写公网地址。`0.0.0.0` 表示接收本机所有 IPv4 地址的连接，不能填到客户端。需要手动指定监听 IP 时，选择 **7 → 4**；已有规则可在 **4 → 修改** 中调整。

## 创建后怎么用

**先放行端口：** 在入口 VPS 的本机防火墙和服务商网页的安全组中，放行 **入口端口的 TCP + UDP**。上面的例子是 `20000`；自动选端口时，以创建结果显示的端口为准。目标服务器也需要允许入口服务器访问目标端口。

**再修改客户端：** 复制一份原来的节点，只修改下面两项：

| 客户端设置 | 按上面的例子填写 |
| --- | --- |
| 服务器地址 | `203.0.113.10`（入口公网地址） |
| 服务器端口 | `20000`（入口端口） |

协议、密码、UUID、加密方式、Reality 公钥、SNI 等参数保持原样。保存并选中这个节点即可测试连接。Realm 转发已有节点，不生成新的 `ss://` / `vless://` 链接，也不额外加密。

## 常用操作

输入 `rnode`，按数字选择即可：

| 想做什么 | 菜单位置 |
| --- | --- |
| 新增转发 | **1** |
| 查看全部规则 | **2** |
| 查看客户端该填的地址和端口 | **3** |
| 修改、启用、停用、删除某条规则 | **4** |
| 查看状态、启动、停止、日志、诊断 | **5** |
| 开启 / 关闭日志（默认关闭） | **5 → 6** |
| 备份、恢复规则 | **6** |
| 更新内核、检查系统、卸载 | **7 → 1 / 2 / 3** |
| 创建 NAT / IPv6 转发或自定义名称 | **7 → 4** |

输入 **0** 返回或退出。修改规则后，客户端可能需要重新连接；修改入口地址或端口后，也要同步修改客户端。

## NAT、域名或 IPv6

- **普通公网 VPS：** 用主菜单 **1** 即可。
- **NAT / 端口映射：** 选择 **7 → 4**。例如服务商分配 `公网 31415 → 本机 20000`，监听端口填 `20000`，公网端口填 `31415`，客户端连接公网地址和 `31415`。映射需提前在服务商或路由器上配置。
- **域名 / DDNS：** 地址可以直接填域名；域名解析或 DDNS 需要自行配置。Cloudflare 使用“仅 DNS”。
- **IPv6 入口：** 选择 **7 → 4**，把监听 IP 设为本机公网 IPv6 或 `::`，向导会自动识别公网 IPv6；也可以在 **4 → 修改** 中调整。目标地址可直接填 IPv6。

## 连不上、更新和卸载

**连不上：** 先确认原节点本来能用、入口端口已放行、客户端地址端口填写正确；NAT 还要检查映射。然后在 **5 → 5** 运行诊断，或执行：

```bash
sudo rnode diagnose
```

诊断检查 TCP 连接；UDP 需要用真实客户端测试。Realm 日志默认关闭，排障时在 **5 → 6** 开启，再到 **5 → 4** 查看；排障完成后到 **5 → 6** 关闭。也可使用 `sudo rnode logs on` / `sudo rnode logs off`。服务运行中切换日志会重启服务，现有连接可能需要重新连接。

关闭日志时，内核日志级别设为 `off`，服务输出丢弃，并清空本工具原有的独立日志文件。systemd 自身的启停记录及已有历史日志由系统管理。升级旧版工具时也会默认关闭日志；已经在新版菜单中选择的日志状态会保留。

**更新工具：** 重新执行上面的安装命令，保留现有规则。**更新内核：** 选择 **7 → 1**，直接回车使用最新正式版。

**占用优化：** 新装或更新内核时优先使用官方 `realm-slim`，保留本工具使用的 TCP / UDP、域名解析、IPv6 和多线程能力；不提供 Slim 的旧版本自动使用标准包。已有标准内核可通过 **7 → 1** 切换。只保留当前内核和一个旧内核，下载包及临时文件在操作结束后删除；管理菜单退出后不驻留后台，不额外添加清理进程。

**备份：** 选择 **6 → 1**，按显示的路径把备份下载到自己电脑。每次修改规则也会自动备份，新版自动备份以 `auto-` 开头，仅保留最近 **10 份**；手动备份和旧版备份保留。**恢复：** 选择 **6 → 2**。

**卸载：** 选择 **7 → 3**，按提示完整输入 `确认卸载`。最后一份规则备份会保留，路径会打印出来。

支持 systemd / OpenRC。安装会自动补齐依赖；更新时继续使用原有规则和 JSON 备份。
